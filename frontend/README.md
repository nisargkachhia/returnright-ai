# ReturnRight AI frontend

React, TypeScript, and Vite client for the ReturnRight AI demo. It talks to the backend MCP server over Streamable HTTP.

Setup and limits are documented in the repository root [README](../README.md).

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173. The UI shows a DEMO MODE banner and uses synthetic purchases only.
